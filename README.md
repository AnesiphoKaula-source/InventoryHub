InventoryHub
InventoryHub is a full-stack inventory management application developed using Blazor and ASP.NET Core Web API. This project demonstrates front-end and back-end integration, debugging, JSON communication, and performance optimization using Microsoft Copilot.

Inventory Management
Product Listing
REST API Integration
JSON Data Exchange
